# summerriverfall_Japan_Store

Multi-shop static sites for GitHub Pages.

Each shop lives in its own subfolder:

- `ginza-zennsoku/` — GINZA ZENNSOKU（銀座禅足）
- `rirasuma-miyamasusaka/` — リラスマ宮益坂店（RIRASUMA）
- `rifurete-dogenzaka/` — リフレーテ道玄坂本店（Rifurete）
- `ariran-dogenzaka/` — 阿里郎(アリラン) リラクゼーション渋谷道玄坂店
- `hyakue-kichijoji/` — 吉祥寺 百会（Hyakue）
- `ichioshi-koenji/` — いちおし健康館 高円寺
- `ashiyu-kagurazaka/` — 足悠 神楽坂店（Ashiyu）
- `ashiyu-azabujuban/` — 足悠 麻布十番店（Ashiyu）
- `rantan-asakusabashi/` — RAN-TAN 浅草橋サロン（ランタン）
- `rirakoro-naga/` — リラころ 長堀橋店（Rirakoro）
- `rirakoro-namba/` — カヌン タイ リラクゼーション 南海難波店（Kanun）

Pages URL pattern:

`https://summeriverfall.github.io/summerriverfall_Japan_Store/<shop-folder>/`
