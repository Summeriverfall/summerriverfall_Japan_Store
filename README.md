# summerriverfall_Japan_Store

Multi-shop static sites for GitHub Pages.

Each shop lives in its own subfolder:

- `ginza-zennsoku/` — GINZA ZENNSOKU（銀座禅足）
- `rirasuma-miyamasusaka/` — リラスマ宮益坂店（RIRASUMA）
- `rifurete-dogenzaka/` — リフレーテ道玄坂本店（Rifurete）

Pages URL pattern:

`https://summeriverfall.github.io/summerriverfall_Japan_Store/<shop-folder>/`
